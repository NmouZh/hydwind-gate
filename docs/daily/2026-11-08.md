### 改了什么

- **登录流程收进 Module**：新增 `flow/LoginFlow`（纯逻辑，不 import Velocity/LimboAPI），承担 submit / verify / timeout 的决策；`LoginSessionHandler` 只剩平台动作（发消息、转服、断开、提示调度）。
- **会话截止时间归属**：`LoginSession.loginDeadline` 在 join 时固定；`beginVerification` 返回 `verificationId`，迟到的校验结果被拒绝；`timeOut` / `timeOutAll` 只认会话自己的 deadline。修掉 reload 调大超时后玩家永久滞留 limbo 的缺陷。
- **管理员动作单一 owner**：`admin/AdminActionService` 独占「先写会话再转服/断开」的顺序；`login/LimboResidents` 是窄 Interface；`AdminCommandExecutor` 只做结果到文案映射。「approve 在 onSpawn 之前」的窗口在 handler 里两次复查，修复卡 limbo。
- **reload 原子发布**：`runtime/RuntimeSnapshot` + `RuntimeHolder`，整代构建、一次发布、关闭旧代际；`HttpWebsiteClient` 实现 `AutoCloseable`，反复 reload 不再泄漏 HttpClient 线程。
- **失败分类**：`VerifyResult` 新增 `CONTRACT_MISMATCH`；`HealthResult` 携带 `transportFailure`；受控重启只对传输层失败触发。契约不兼容只告警，不再重启一个其实活着的网站。
- **命令语法单一来源**：`command/CommandGrammar` 统一词表、解析、补全、requiresTarget；删除 `AdminCommandRequest.NONE`，执行器 switch 变成穷尽表达式。
- **配置窄视图**：五个 settings record；校验从三处集中到 record 紧凑构造器，非法值从静默回退改为启动/重载失败。
- **其余**：`KaomojiCode` → `LoginCode`；`AdminStatusRenderer` 从 `AdminStatus` 拆出；`LimboCompat` 校验 LimboAPI ≥ 1.2.0；`Messages.placeholderWarnings` 为重载时的占位符缺失告警提供入口；`LimboLoginService.shutdown()` 逐个关闭仍登记的会话。
- **文档**：新增 `docs/adr/0002-gate-flow-deepening.md`；spec 0002、README、manual-test、GLOSSARY、config.yml 注释同步。

### 改了什么

- **会话截止时间归属**：`LoginSession.loginDeadline` 在 join 时固定；`beginVerification` 返回 `verificationId`，迟到的校验结果被拒绝；`timeOut` / `timeOutAll` 只认会话自己的 deadline。修掉 reload 调大超时后玩家永久滞留 limbo 的缺陷。
- **管理员动作单一 owner**：`admin/AdminActionService` 独占「先写会话再转服/断开」的顺序；`login/LimboResidents` 是窄 Interface；`AdminCommandExecutor` 只做结果到文案映射。「approve 在 onSpawn 之前」的窗口在 handler 里两次复查，修复卡 limbo。
- **reload 原子发布**：`runtime/RuntimeSnapshot` + `RuntimeHolder`，整代构建、一次发布、关闭旧代际；`HttpWebsiteClient` 实现 `AutoCloseable`，反复 reload 不再泄漏 HttpClient 线程。
- **失败分类**：`VerifyResult` 新增 `CONTRACT_MISMATCH`；`HealthResult` 携带 `transportFailure`；受控重启只对传输层失败触发。契约不兼容只告警，不再重启一个其实活着的网站。
- **命令语法单一来源**：`command/CommandGrammar` 统一词表、解析、补全、requiresTarget；删除 `AdminCommandRequest.NONE`，执行器 switch 变成穷尽表达式。

### 最终验收发现的真问题（已修）

- **同名重复登录可清掉目标会话**：Velocity 拒绝重复登录时仍触发 `DisconnectEvent`，携带目标玩家的 UUID；`onDisconnect` 无条件 `quit` 让未认证者可以删除别人的会话。现在忽略 `CONFLICTING_LOGIN`。
- **管理员按名查找用 `equalsIgnoreCase`**：离线模式下大小写变体是不同账号，Unicode 简单大小写（`ſ`/`s`）可让管理员放行错人。改为精确匹配。
- **迟到的成功结果把会话置成 TIMED_OUT 后没人踢**：`timeOutAll` 现在也返回“已标记但未清理”的会话，sweep 能重试到真正断开。
- **`timeOutNow` 可能误踢刚被放行的玩家**：现在检查 `authenticated` 并复核 `sessionStore.timeOut`，复核不成立时撤销关闭标记。
- **旧连接的迟到 `onDisconnect` 会删掉重连后的新 handler**：`unregister` 改为按 handler 身份移除。
- **reload 关闭旧 HttpClient 后旧 handler 的 restartTrigger 指向已关闭客户端**：触发受控重启时改取当前代际。
- **README 的 systemd 示例重启的是 Velocity**：会踢掉全员且网站仍未恢复；改为重启 hydwind-web.service。
- **LimboAPI 安装命令缺 SHA-256 校验**、`/run/hydwind` 无持久化说明、token 注释引导写进配置文件——都已修正。
- **手动测试三条不可执行**：`expired` 会先被登录超时踢出、`used` 认证后已无 `/login` 入口、`401` 假设 reload 会重读环境变量。都改为可执行步骤。

## Claude Code · 02:20

并发评审最后返回，确认了一类必须修的原子性竞态：

- `timeOutNow` 原先“先 CAS 关闭、再复核 store、复核失败则回滚”。管理员若在
  中间 approve，会留下“会话已认证但 handler 拒绝转服、提示任务继续刷”的玩家；
  若在中间 kick，会留下“玩家在线但从 sessions 与 residents 两个登记表消失”。
  现在改为先让 store 判定（`timeOut` 返回 true 才继续），再 CAS 关闭，不回滚。
- `forceAuthenticate` / `forceAuthenticateByGameId` 只接受 PENDING/VERIFYING，
  不再复活 TIMED_OUT；AdminActionService 对已超时会话返回 NOT_FOUND。
- `kick` 改用 `removeIfSession(uuid, expected)`，只删刚才查到的会话，
  不会误删玩家在查找与删除之间重连建立的新会话。
- `onSpawn` 的提前转服改用 CAS 与 `approveByAdmin` 互斥；任务赋值后再复核
  closed/authenticated，关闭“取消早于赋值”的窗口。
- `LimboLoginService` 增加 closed 标志与 volatile 字段，shutdown 后 register
  会直接关闭 handler，spawn 不再触碰已 dispose 的 limbo。

新增 3 条回归测试（TIMED_OUT 不可复活、removeIfSession 不删新会话、
approve 已超时会话返回 NOT_FOUND）。当前 JUnit **274 个测试全绿**。

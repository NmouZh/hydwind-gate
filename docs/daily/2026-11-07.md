修复 `feat/login-gate` 代码审查遗留问题（分支 `fix/review`），不重新审查，直接按清单改。

### 改了什么

- **429 限流**：`VerifyResult` 新增 `RATE_LIMITED` 与 `retryAfterMs`、`attemptsRemaining`；`HttpWebsiteClient` 把 429 映射为限流，优先读响应体的 `retryAfterMs`，缺失时回退 `Retry-After` 头。`LoginManager` 显示「尝试过多，请 X 秒后再试」，不触发不可达回调（因此也不触发探活与受控重启）。
- **409 game_id_mismatch**：解析可选的 `expectedGameId`，有值时文案点名「此账号对应游戏 ID 为 X」，没有时沿用通用文案。
- **归一化统一**：`LoginManager` 改用 `KaomojiCode.normalize`，ASCII 部分大小写不敏感；`isBlankOrTooLong` 真正接进提交路径（空码/超长码不请求网站），删除无用的 `looksLikeFallback`。
- **成功信息与对话框**：成功文案按 `role=admin` 分流，优先显示中文别名；对话框正文保证包含网站 URL（模板没写 `{url}` 时自动补上）。
- **reload 不丢重启策略**：插件保留同一个 `RestartPolicy` 实例，用 `reconfigure(RestartSettings)` 更新参数，冷却与窗口内计数不再清零。
- **冻结命令**：`/login` 无条件放行，`/hydwind` 仅在有 `admin.permission` 时放行，其余命令取消。
- **文案可配置**：`AdminService` / `AdminCommand` 的中文文案移到 `Messages.admin`（`AdminMessages`），并在 `config.yml` 增加 `messages.admin` 段。
- **结构清理**：抽出 `FreezeController.cancelIfFrozen`、`LoginSessionStore` 的超时判断；新增 `web.Urls.stripTrailingSlashes`，`RestartPolicy` 增加接收 `RestartSettings` 的构造器。
- **对话框按钮**：Paper Dialog 的静态动作支持 `openUrl`，`重新打开网站` 按钮现在真的打开网站，不再走自定义 reopen 事件。
- **文档**：README 统一用「登录码」；spec 模块列表去掉未实现的 `HealthProbe`，注明健康检查是 `WebsiteClient.health()`。
